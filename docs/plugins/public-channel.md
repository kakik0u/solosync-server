# 公開チャンネル

管理画面で「公開チャンネル」をONにし、同期データを準備した後、公開したいチャンネルを選んでURLを作成します。URLにアクセスした人は認証なしでそのチャンネルのメモを閲覧できます。本文・投稿時刻・表示名に加え、第1段階のRich Embedを保存順にカード表示します。更新前に作成した公開URLにもEmbedが表示されます。

Embedのタイトル、説明、リンク、色、author、footer、日時、画像、thumbnail、fieldsを表示します。文字列はHTMLをエスケープし、改行を保ちます。Markdownは解釈しません。スマートフォンでは横並びfieldsを縦に並べます。

HTTP(S)のURL画像は閲覧者のブラウザーから外部ホストへ直接読み込みます。Refererは送信しませんが、画像ホストには閲覧者のアクセスが届きます。サーバーによる取得や画像プロキシはありません。管理添付画像は未対応表示にし、添付IDやファイル本体を公開しません。

表・グラフ・未知のblockや将来形式は保存済みの要約テキストを表示します。壊れたJSON、1MiBを超えるデータ、要約のない未対応内容は未対応表示にし、本文や他のメモは表示を続けます。要約は最大4KiBです。生のpayload JSONは公開しません。

プラグイン自体のOFFまたは個別URLの「公開を停止」は直ちに表示を止めます。URL再生成で古いURLは使えなくなります。検索エンジンには `noindex` を指定しますが、URLを知る人からの閲覧を防ぐものではありません。公開前にチャンネルの内容を確認してください。

ページは読み取り専用です。同期データの読み取りモデルが古いときは最新と偽らず `503` を返します。チャンネル削除時は公開ページも表示しません。

更新時は管理画面のDBマイグレーションまたは `php bin/migrate.php` を適用し、データ準備を実行してください。自動更新と定期maintenanceも共有migrationを適用します。読み取りモデルrevision 3は保存済みSyncPackからblockを再構築するため、クライアントの全量再送は不要です。再構築が完了するまでは503になります。Embedを新規作成・同期する前にGroup内の全端末を対応版へ更新してください。
